GitHub Pages で常設公開する手順

完了すると、どのPC・スマホからでも掲示を開けます（このPCの電源は不要です）。

公開後のURLの形（例）

https://あなたのGitHubID.github.io/shisetsu-keiji-2026/kohokudai/

事前準備（初回のみ）

  1. GitHub で無料アカウントを作成
  2. Git for Windows をインストール（未導入の場合）

手順1：GitHubにリポジトリを作る

  1. GitHubにログイン → 右上「＋」→ New repository
  2. Repository name: shisetsu-keiji-2026（変更可。変更した場合は data/hosting.yaml も合わせる）
  3. Public を選択 → Create repository

手順2：GitHub Pages を有効化

  1. 作成したリポジトリ → Settings → 左メニュー Pages
  2. Source: GitHub Actions を選択（Deploy from branch ではない）
  3. ※ 初回 push 後、Actions が自動でデプロイします

手順3：PCからアップロード（push）

PowerShell で、このフォルダ（院内掲示）を開いて実行します。
あなたのGitHubID は自分のユーザー名に置き換えてください。

cd "c:\Users\SUZUKI\Desktop\院内掲示"

git init
git add .
git commit -m "施設基準掲示 令和8年度改定"
git branch -M main
git remote add origin https://github.com/あなたのGitHubID/shisetsu-keiji-2026.git
git push -u origin main

push 時に GitHub のログインを求められたら、ブラウザで認証します。

手順4：公開URLを確定する

  1. data/hosting.yaml を開き、github_user: に GitHub のユーザー名を記入
    例: github_user: suzuki-taro
  2. PowerShell で再生成: 
    python scripts/generate.py
  3. GitHub → リポジトリ → Actions で緑のチェック（成功）を確認
  4. Settings → Pages に表示された URL を開く（2〜3分かかることがあります）
  5. GitHubPages-公開URL.html に各院のリンクが出力されます

手順5：上司・関係者へ送る

GitHubPages-公開URL.txt のURLをメールやチャットに貼り付けて送付してください。

注意

  • リポジトリが Public だと誰でもURLから閲覧できます（社内確認・上司確認向け）。
  • 非公開にしたい場合は GitHub の有料プランが必要です。
  • 文言を直したら python scripts/generate.py → git add . → git commit → git push で更新が反映されます。

掲示内容を更新するとき

python scripts/generate.py
git add .
git commit -m "掲示内容を更新"
git push
